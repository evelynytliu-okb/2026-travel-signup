============================================================
 2026 員工旅遊報名表 — 設定說明（只需做一次，約 10 分鐘）
============================================================

檔案：
  • index.html      → 員工填寫的報名網頁
  • Code.gs         → 後端程式（貼到 Google Apps Script）
  • 設定說明.txt    → 本檔

做法概念：
  網頁(index.html) → 送出 → Google Apps Script → 寫進 Google 試算表
  承辦同事只要打開那份試算表，就能即時看到所有報名與自動加總。


────────────────────────────────────────────
 步驟 1：建立 Google 試算表
────────────────────────────────────────────
1. 用你的 Google 帳號開啟 https://sheets.google.com
2. 建立一份新的空白試算表，命名為「2026員工旅遊報名」。
   （分頁與標題列程式會自動建立，不用手動弄。）


────────────────────────────────────────────
 步驟 2：貼上後端程式
────────────────────────────────────────────
1. 在這份試算表上方選單：擴充功能 → Apps Script
2. 把預設的程式碼全部刪掉。
3. 打開本資料夾的 Code.gs，整段複製、貼進去。
4. （選填）想在每筆報名時收 Email 通知：
   把 Code.gs 第 14 行的  const NOTIFY_EMAIL = '';
   改成   const NOTIFY_EMAIL = 'evelyn.evagor@gmail.com';
5. 按上方的「儲存」圖示。


────────────────────────────────────────────
 步驟 3：部署成「網頁應用程式」
────────────────────────────────────────────
1. 右上角「部署」→「新增部署作業」。
2. 齒輪圖示「選取類型」→ 選「網頁應用程式」。
3. 設定：
     • 執行身分：我（你自己）
     • 誰可以存取：「所有人」(Anyone)   ← 一定要選這個，員工才送得出來
4. 按「部署」。第一次會要求授權，依指示用你的帳號允許即可
   （若出現「未經驗證」警告：進階 → 前往(專案名稱)(不安全) → 允許）。
5. 複製畫面上的「網頁應用程式網址」
   （長得像 https://script.google.com/macros/s/AKfy..../exec）


────────────────────────────────────────────
 步驟 4：把網址填進網頁
────────────────────────────────────────────
1. 用記事本或編輯器打開 index.html。
2. 找到這一行（約在 <script> 開頭）：
       const ENDPOINT = "請貼上_你的_Apps_Script_網址";
3. 把引號中間換成步驟 3 複製的網址，存檔。例如：
       const ENDPOINT = "https://script.google.com/macros/s/AKfy..../exec";


────────────────────────────────────────────
 步驟 5：把網頁放上線給員工填
────────────────────────────────────────────
任選一種免費方式（擇一即可）：
  A. Netlify Drop：開 https://app.netlify.com/drop ，把 index.html
     拖進去，馬上得到一個網址，傳到公司群組即可。
  B. GitHub Pages、公司內部網站、Google Sites 等也可以。
  ※ 直接把 index.html 寄給每個人「在電腦開」也能用，
    但放上線、給「一個網址」最方便，手機也能填。


────────────────────────────────────────────
 設定公司補助（在試算表維護，不用碰網頁）
────────────────────────────────────────────
• 補助名單視為「正式名單」：只有列在「補助設定」分頁的工號才有補助。
• 完成步驟 2、3 部署後，試算表會自動出現一個「補助設定」分頁。
  在那個分頁登記每位可補助的工號與金額：
     A 欄＝工號     B 欄＝補助金額（例如 10000、5000、0）     C 欄＝備註
  例如：
        工號     補助金額   備註
        A1024    10000      全額補助
        A1031    5000       入職未滿一年
• 沒列在「補助設定」分頁的工號 → 補助 0 元
  （避免新進人員把工號打錯卻拿到預設金額）。
• 改完馬上生效，不用重新上傳網頁。
• 員工填表時輸入工號，網頁會自動向後端查出補助、算出「應補差額」
  ＝ 總金額 −（公司補助），補助大於總金額時差額為 0。
  （送出時後端會以「補助設定」分頁為準再算一次並存檔，防止金額被改。）

  ※ 若補助名單需要保密：因網頁是逐筆用工號查詢、不會一次載入整份名單，
    一般員工看不到別人的補助金額。


────────────────────────────────────────────
 完成！日常使用
────────────────────────────────────────────
• 員工：點網址 → 填資料 → 送出。
• 承辦同事：打開「2026員工旅遊報名」試算表 →「報名清單」分頁，
  每筆報名會即時新增一列，含房型、人數、總金額與同行者明細。
• 想統計總金額：在試算表用 =SUM(H:H) 之類即可。

────────────────────────────────────────────
 後台新功能（v4）與更新方式
────────────────────────────────────────────
這次新增了 5 項功能，更新方式有兩步（都要做，否則新功能不會生效）：

  【更新步驟 A：更新後端 Code.gs】
   1. 開試算表 → 擴充功能 → Apps Script。
   2. 把整段程式刪掉，重新貼上新的 Code.gs（本資料夾這份）。
   3. 「部署」→「管理部署作業」→ 對現有的網頁應用程式按鉛筆(編輯)
      → 版本選「新版本」→「部署」。
      ★ 用「編輯現有部署」更新版本，網址(ENDPOINT)才不會變、不用改網頁。
        若不小心建了「新部署」會產生新網址，那就得把新網址貼回三個 html。
   4. 程式會自動：在「報名清單」最後補一欄「部門」、在「設定」分頁補一列
      「報名開關」(B2)。舊資料不受影響。

  【更新步驟 B：更新三個網頁】
   把 index.html、dashboard.html、share.html 重新上傳到原本的網址
   （GitHub Pages：用 evelynytliu-okb 帳號登入，到 repo 覆蓋同名檔案）。

  新功能說明：
   1. 報名表多了「部門」下拉選單（依組織圖・部級，以「處」分組）。
   2. 後台「💰 補助名單」按鈕：輸入密碼後可直接在後台新增／修改／刪除
      補助名單並儲存（等同編輯「補助設定」分頁，不必另外開試算表）。
   3. 後台名單上方有「部門篩選」與「搜尋」框，可快速篩選。
   4. 名單每列有「✏️ 編輯」：輸入密碼後可修改該列的單一欄位
      （姓名、工號、部門、身分證、房型…等；費用／補助為自動計算不開放改）。
   5. 報名截止日 2026/06/10 會顯示在報名表與掃碼頁（僅顯示、不會自動關）。
      後台右上「報名開關」可手動「截止／重新開放」報名；關閉後員工送出會被擋
      （已送出的資料不受影響）。也可直接在「設定」分頁 B2 填「開放／關閉」。

  ※ 上述後台操作都需要「設定」分頁 B1 的後台密碼。
